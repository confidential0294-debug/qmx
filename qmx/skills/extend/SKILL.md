# Extend Skill

## Overview
**Type:** Workflow  
**Name:** extend  
**Purpose:** Extension implementation workflow with compatibility and integration

## Description
The extend skill implements system extensions and plugins while ensuring compatibility, proper integration, and maintainability of extended functionality.

## Usage

```bash
skill: "extend"
```

### Parameters
- `base`: Base system to extend
- `extension`: Extension requirements
- `compatibility`: Compatibility requirements
- `integration`: Integration points

## Process

1. **Extension Analysis**: Understand extension requirements
2. **Compatibility Check**: Verify compatibility with base
3. **Design**: Design extension architecture
4. **Implementation**: Implement extension
5. **Integration**: Integrate with base system
6. **Testing**: Test extension functionality

## Output Structure

```
extend-output/
├── extension-design.md   # Extension design
├── compatibility-report.json # Compatibility analysis
├── implementation/       # Extension code
├── integration-guide.md  # Integration documentation
└── test-results.json     # Test results
```

## Integration

- **integrate**: Integration testing
- **test**: Extension testing
- **document**: Document extension
- **review**: Review extension quality

## Best Practices

- Follow extension patterns
- Maintain loose coupling
- Document extension points
- Test compatibility
- Plan for versioning
