## Usage

### 1. Run Setup

```bash
qmx setup
```

### 2. Verify Installation

```bash
qmx doctor

# Output:
✓ QMX Installation
✓ Project Configuration
✓ MCP Servers
  All 4 MCP servers available
```

### 3. Use Skills

```bash
# In Qwen Code
$plan "Implement authentication"
$team 3:executor "Fix TypeScript errors"
$review "Review the code"
```

### 4. Use Agents

```bash
# In Qwen Code
/prompts:architect "Review the architecture"
/prompts:planner "Plan the implementation"
/prompts:executor "Implement the feature"
```
