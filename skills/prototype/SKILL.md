# Prototype Skill

## Overview
**Type:** Workflow  
**Name:** prototype  
**Purpose:** Rapid prototyping workflow with iteration and validation

## Description
The prototype skill enables rapid prototype development for validating concepts, testing approaches, and gathering feedback before full implementation.

## Usage

```
skill: "prototype"
```

### Parameters
- `concept`: Concept to prototype
- `fidelity`: Prototype fidelity level
- `validation`: Validation requirements
- `iterations`: Planned iterations

## Process

1. **Concept Definition**: Define prototype goals
2. **Scope Definition**: Define prototype scope
3. **Rapid Development**: Build prototype quickly
4. **Validation**: Validate with stakeholders
5. **Feedback Collection**: Gather feedback
6. **Iteration**: Refine based on feedback

## Output Structure

```
prototype-output/
├── prototype/            # Prototype code
├── validation-results.md # Validation results
├── feedback.md           # Collected feedback
├── iterations/           # Iteration history
└── recommendations.md    # Next step recommendations
```

## Integration

- **research**: Research prototype approaches
- **compare**: Compare prototype options
- **iterate**: Iterate on prototype
- **plan**: Plan full implementation

## Best Practices

- Build quickly, iterate often
- Focus on key concepts
- Gather early feedback
- Don't over-engineer
- Know when to stop

## Related Skills

research, compare, iterate, plan, validate, test
